# Arcade
A collection of classic games implemented in HTML, CSS, and JavaScript.

## Minesweeper
A classic implementation of the Minesweeper game using HTML, CSS, and JavaScript.

### How to Play
1. Open `index.html` in your web browser
2. Choose a difficulty level from the dropdown menu:
   - Beginner: 9x9 grid with 10 mines
   - Intermediate: 16x16 grid with 40 mines
   - Expert: 16x30 grid with 99 mines
3. Click on a cell to reveal it
   - If it's a mine, you lose
   - If it's not a mine, it shows how many adjacent mines there are
   - If there are no adjacent mines, all adjacent cells are automatically revealed
4. Right-click on a cell to flag it as a potential mine
5. Win by revealing all cells that don't contain mines

### Game Features
- Three difficulty levels
- Mine counter to track remaining mines
- Game status messages
- Auto-reveal for empty cells
- Responsive design for various screen sizes
